# Changelog

## 0.2.1

- The macOS app is now signed and notarized by Apple, and installs from a disk image by dragging it to Applications.
- After this update on macOS, you may need to allow Microphone and Accessibility access again.

## 0.2.0

- KoeBoard now checks for updates and can install them from the Updates tab or the menu.
- Settings opens with these release notes the first time a version runs.
- New app and menu bar icons.
- The size of dictated text is now easier to find and adjust in Settings.

## 0.1.0

- First release: on-device dictation for macOS and Windows.
